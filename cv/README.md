# Carpeta del CV

Coloca aquí tu CV en formato PDF (por ejemplo: `mi_cv.pdf`).

Esta carpeta está excluida del control de versiones (ver `.gitignore`), así que tu CV nunca se sube al repositorio. El agente lee cualquier PDF que encuentre aquí para extraer tu perfil (roles, skills, experiencia) y usarlo como base de la búsqueda de empleo.
